# 限界ふるさと納税（最小版）

年収と家族構成から限度額の目安を計算し、限度額を使い切る返礼品の組み合わせを提案する無料Webツールです。
ファイルは `index.html` の1つだけです。計算はすべてブラウザ内で行い、入力データはサーバーに送信されません。

## 公開手順（GitHub＋Cloudflare Pages・どちらも無料）

### 1. GitHubにファイルを置く
1. GitHubの無料アカウントを作成する（すでにある場合は不要）
2. 新しいリポジトリを作成する（例：`genkai-furusato`、Public を選ぶ）
3. リポジトリ画面の「Add file → Upload files」から `index.html` をドラッグ＆ドロップし、「Commit changes」を押す

### 2. Cloudflare Pagesで公開する
1. Cloudflareの無料アカウントを作成する
2. ダッシュボードで「Workers & Pages → Create → Pages → Connect to Git」を選ぶ
3. 上のGitHubリポジトリを選び、設定は初期値のまま進める
   - Framework preset：None
   - Build command：空欄
   - Build output directory：`/`
4. デプロイが終わると `https://genkai-furusato.pages.dev` のようなURLで公開される
5. 以後、GitHub側のファイルを更新すると、自動で再公開される

※テストだけなら、GitHubの「Settings → Pages」で GitHub Pages として公開することもできます。

## 公開後の作業（収益化の準備）
1. 公開URLを使ってASP（A8.net、バリューコマース、もしもアフィリエイト等）に登録し、ふるさと納税ポータルの広告に提携申請する
2. 提携が通ったら、`index.html` の中の `ITEMS` データを実在の返礼品に差し替え、各 `url` にアフィリエイトリンクを設定する（空文字の間は「リンク準備中」と表示される）
3. 返礼品データを差し替えたら、GitHubに再アップロードする（Cloudflare側は自動で再公開）

## 計算について
- 年収からの概算：社会保険料を年収の15%と仮定し、住民税の所得割額を推計したうえで、総務省の式「所得割額 × 20% ÷（90% − 所得税率 × 1.021）＋ 2,000円」で限度額の目安を出す
- 住民税決定通知書の所得割額を入力した場合は、そちらを優先する
- 画面には目安の9割を「安全めの目安」として併記し、組み合わせ提案の予算には安全めの金額を使う
- 住宅ローン控除・医療費控除・iDeCoなどがあると実際の限度額は下がるため、ページ内に注意書きを表示している

## 既知の制限（最小版のため）
- 返礼品はサンプルデータ（24品目・食品6ジャンル）
- 給与収入のみ対応（自営業・年金収入などは未対応）
- 組み合わせは「各品目1つまで・予算内で合計最大」を自動計算する
