# 限界ふるさと納税

年収と家族構成から、ふるさと納税の限度額の目安を計算し、限度額を使い切る返礼品の組み合わせまで提案する無料Webツールです。

## できること

- 年収と家族構成を入れるだけで、自己負担2,000円で済む寄附額の目安を表示します
- 住民税決定通知書の「所得割額」を入力すると、より実態に近い目安を計算します
- 目安の9割を「安全めの目安」として併記します
- 好きなジャンル（米・肉・魚介・果物・スイーツ・飲料）を選ぶと、残りの枠に収まる返礼品の組み合わせを自動で提案します
- すでに寄附した額を差し引いて、残りの枠で計算できます

## 使い方

1. 年収と家族構成を入力して「限度額の目安を計算する」を押す
2. すでに寄附した額があれば入力する
3. ジャンルを選ぶと、予算内で合計が最大になる返礼品の組み合わせが表示される

## 注意事項

- 表示される限度額は目安です。住宅ローン控除・医療費控除・iDeCoなどがある場合、実際の限度額は下がります
- 正確な金額は、住民税決定通知書や公式のシミュレーターでご確認ください
- 今年分の寄附の締切は12月31日です。ワンストップ特例の申請は翌年1月10日必着・寄附先5自治体までです
- 本ページには広告（アフィリエイトリンク）が含まれる場合があります

## 技術について

- ファイルは `index.html` の1つだけです
- 計算はすべてブラウザ内で行い、入力したデータがサーバーに送信されることはありません
